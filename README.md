# calculator

Что это за проект?

Это учебная работа для расчета объема воды, необходимого для полива сельскохозяйственной культуры. Количество воды
зависит от вида культуры, типа почвы, температуры воздуха, площади участка и количества дней без осадков.

Ссылка на проект: https://twity007.github.io/calculator/index.html
